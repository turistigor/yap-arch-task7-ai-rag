# Подготовка базы знаний

В качестве исходной базы знаний мною была взята подборка статей категории ["Бег - Тренировки"](https://marathonec.ru/topics/running/training/)
с сайта https://marathonec.ru.

Для выкачивания написан [python-модуль](knowledge_base/__main__.py).  
Для запуска необходимо проделать следующие шаги:
1. Установить:
    - [python >= 3.12](https://www.python.org/downloads/)
    - [пакетный менеджер uv](https://docs.astral.sh/uv/getting-started/installation/)
2. Выполнить команды:
    ```bash
    cd <project_dir>/knowledge-base
    uv sync
    source .venv/bin/activate
    python3 -m knowledge_base all
    ```
3. Результаты будут в папках:
    - knowledge-base/data - оригинальная база знаний,
    - knowledge-base/data_replaced - измененная база знаний,
    - knowledge-base/terms_map.json - словарь замены терминов.

## Логика замены
Для замены взяты общеизвестные в беговом сообществе термины: тест Купера, каденс, фартлек, ЧСС и МЧСС. Онии заменены на смешные слова с сохранением склонений во избежание потери смысла. Для проверки производилось выборочное перечитывание, а также проверка числа вхождений исходных терминов в оригинальной базе с числом вхождений в измененной. Тестирование показало хорошие результаты, замена признана корректной.
